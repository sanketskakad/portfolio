## Technical Overview

High-performance portfolio application built with React 19, GSAP, RoughJS, and Tailwind CSS v4. Showcases stateful AI engineering architectures, live model deployments, and technical publications.

### Core Stack
- **Frontend**: React 19, Tailwind CSS v4, GSAP ScrollTrigger, Framer Motion, RoughJS
- **Markdown Processing**: `marked` with custom typography styling
- **Build System**: Vite 8 with HMR
